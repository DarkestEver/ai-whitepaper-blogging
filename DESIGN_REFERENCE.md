# Design Reference - Applied Templates

## Inspiration Sources
1. **AM-Tech Newz** - Colorful banners, featured carousel, bold cards
2. **TechBite** - Category sections, organized grid, clear hierarchy  
3. **Sound Square** - Multi-colored tiles, vibrant gradients, section-based
4. **Newsy** - Image-heavy cards, playful colors, engaging layout
5. **ViralBuzz** - Card grid with large images, saturated colors

## Key Design Elements to Apply

### 1. Featured Section (Top Priority)
- Large hero/banner area (300-400px)
- Featured paper with big image
- Bold typography overlay
- Call-to-action button

### 2. Category Sections
- Organize papers by category/topic
- Each section has distinct color
- "Latest", "Popular", "Trending" sections
- Numbered badges (01, 02, 03)

### 3. Card Grid
- Large cover images (300x180px minimum)
- Colorful background cards
- Title overlay or below card
- Hover effects with lift

### 4. Color Palette (Vibrant)
- Reds: #FF4757, #EE5A6F
- Blues: #1E90FF, #4A90E2
- Greens: #2ED573, #26D07C
- Purples: #9C27B0, #C945D8
- Oranges: #FFA502, #FF6B35
- Teals: #00B4D8, #0096FF

### 5. Typography
- Large headings (48-64px)
- Bold weights (600-700)
- High contrast colors
- Clear visual hierarchy

### 6. Layout Changes
- Hero takes 30% of viewport
- Multiple "sections" with names
- Cards in 3-column grid (desktop)
- Better spacing between sections
- Clear section dividers
