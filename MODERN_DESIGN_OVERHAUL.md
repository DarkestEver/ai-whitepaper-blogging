# Modern Design Overhaul - WPBlog Home

**Status**: In Progress | Inspired by Signal Library design
**Target**: Transform basic prototype design into polished, modern research library

---

## Design Improvements

### 1. Enhanced Color Palette
- **Navy/Dark Teal**: #1a3a52, #2d5a6b (for featured cards)
- **Lavender**: #6b5b95 (for accent cards)
- **Gold/Tan**: #b8956d (for warm accents)
- **Mint/Teal**: #7ec8c2 (for fresh accents)

### 2. Hero Section
- Increased height to 640px
- Gradient background (sage → cream)
- Larger typography (96px headings)
- Better spacing and visual impact

### 3. Featured Carousel
- Color-coded cards (blue, purple, sage, cream, gold)
- Gradient backgrounds
- Enhanced hover effects
- Serif typography emphasis

### 4. Paper Cards
- Gradient backgrounds on card art
- Better hover effects (lift + shadow)
- Colored category badges
- Improved typography hierarchy

### 5. Section Headers
- Add numbered badges (01, 02, 03)
- Color-coded separators
- Better visual hierarchy
- More generous spacing

### 6. Overall Changes
- Expand whitespace
- Better typography sizing
- Enhanced color contrast
- More polished, modern feel
